# Audiobook E-Commerce Website

A front-end e-commerce website for browsing and purchasing audiobooks, developed as a university project using HTML, CSS and JavaScript.

The project focuses on building a multi-page shopping interface with audiobook categories, individual product pages and a simulated purchasing experience.

> **Note:** This is a front-end project. Payments, backend services and real user accounts are not implemented.

## Features

The website includes:

- Audiobook catalogue
- Individual audiobook pages
- Fiction and non-fiction categories
- Genre-based browsing
- Shopping cart interface
- Checkout interface
- Deals and promotions
- Events and promotions
- Newsletter page
- Contact page
- Responsive website layout

## Audiobook Categories

Users can browse books across several categories, including:

- Fiction
- Non-fiction
- Children's books
- Mystery and thriller
- Romance
- Science and fantasy
- Self-help
- History

Individual pages were also created for books available throughout the website.

## Shopping Interface

The project includes a front-end shopping experience with dedicated cart and checkout pages.

These interfaces demonstrate how an e-commerce purchasing flow could be structured, although no real transactions or backend payment processing are implemented.

## How to Run

No installation is required.

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

The website will run locally in the browser.

## Project Purpose

This project was developed to practise front-end web development and the creation of a multi-page e-commerce website.

It provided experience structuring a larger website across multiple pages while working with HTML, CSS and JavaScript to create the interface and user experience.
